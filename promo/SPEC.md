# SPEC — MOCA 숏폼 30 s (세로 9:16)

GOAL:   본 사람이 «내 차 점수를 알려 주고 고치면 등급이 오르는 차량용 앱 MOCA» 를 기억하고 앱 이름을 말할 수 있다.
OUTPUT: HyperFrames 0.9.46, 1080 x 1920, 30 fps, H.264 High yuv420p ~11 Mbps, AAC 48 kHz stereo, `out/MOCA_shorts_30s.mp4`
TIME:   30.000 s x 30 fps = 900 frames. BPM 92.29 (1 beat = 0.6495 s = 19.5 f, 1 bar = 2.598 s). 곡 `assets/music/bgm.mp3` 0.0 s 부터 30.0 s 까지 그대로 사용(0~1.75 s 라이저, 1.765 s 드롭, 29.0 s 부터 곡이 잦아듦), 마지막 1.6 s 페이드아웃. 박자 격자: beat k = 2.647 + 0.6495 k.

## 이야기(척추)
한 대의 차, 한 개의 숫자: B · 75 (앱 화면 실제 값). 켜자마자 점검 -> 어디가 문제인지 -> 말로 묻기 -> 정비소 길 안내 -> 연습 상대와 대전(75 대 88 로 짐) -> ABS 해결 -> A · 83.
사실은 모두 `assets/footage/INDEX.md` 와 녹화 화면에 있는 것만. 지어낸 수치·기능 없음. 금지어(«데모») 화면·자막 없음(아래 가림 처리).
