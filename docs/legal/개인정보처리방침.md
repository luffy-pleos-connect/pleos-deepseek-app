# MOCA 개인정보 처리방침 (초안)

시행일: 2026-11-14
서비스명: MOCA (Pleos Connect 차량용 앱)
문의: 해적단 익명 메일 (제출 시 기입)

> 이 문서는 공모전 제출용 시제품 기준입니다. 실제 개인정보 보호법상 "개인정보 처리방침" 공개 의무는 사업자에게 발생하며, 본 시제품은 그 형식을 갖춰 작성했습니다.

**한눈에 보기**

- 서버로 가는 것은 **AI 질문(`POST /chat`) 하나**입니다. 질문 글자와, 앱이 만든 차량 요약이 갑니다.
- 점검 기록은 **기기 안 파일**에만 있습니다. 서버에 올리지 않습니다.
- 위치·좌표, 차대번호, 타이어 공기압 수치, 점검 기록 원본은 **보내지 않습니다.**
- 앱 사용 기록(어느 화면을 눌렀는지 등)은 **수집하지 않습니다.**
- 지우려면 **설정 > 내 데이터 삭제**입니다. 동의 철회도 이 버튼으로 합니다.

## 1. 수집하는 정보

| 구분 | 항목 | 수집 방법 | 어디에 있나 | 목적 |
|---|---|---|---|---|
| 기기 식별 | 임의 생성 기기 ID(UUID v4) | 앱이 기기 안에서 생성 | 기기 안. AI 질문(`/chat`)을 보낼 때 함께 서버로 감 | 서버의 요청 횟수 제한 |
| 기기 식별 | 기기 비밀값 | 앱이 기기 안에서 생성 | 기기 안. 데이터 삭제 요청 때만 서버로 감 | 예전에 올린 요약을 지울 때 본인 확인 |
| 사용자 입력 | 닉네임(한글·영문·숫자 2~10자. 비우면 「드라이버」+숫자 4자리를 자동 생성) | 첫 실행 화면, 설정 | 기기 안 | 화면에 표시(월간랭킹의 내 이름) |
| 차량 상태 | 읽은 차량 값, 구역 5개 점수, 건강·관리·종합 점수, 등급, 점검 시각 | Vehicle SDK에서 읽어 앱이 계산 | 기기 안 파일 | 상태관리·대전·월간랭킹 표시 |
| 음성·글자 질문 | 인식된 질문 글자 또는 키보드로 입력한 글자 (오디오 아님) | Android 음성 인식, 키보드 | 서버로 보내 AI 답변에 씀 | AI 답변 생성 |
| 차량 요약(AI 질문과 함께) | 아래 2장 표의 항목 | 앱이 만든 도구 결과 | 서버로 보내 AI 답변에 씀 | 답이 내 차 값을 근거로 하게 함 |

**수집하지 않는 것**
- 위치·좌표. 내비 안내를 요청해도 좌표를 서버로 보내지 않습니다.
- VIN(차대번호).
- 타이어 공기압 수치(kPa).
- 점검 기록 원본.
- 앱 사용 기록(화면 이동, 버튼 누름 등). 이 기능은 없어졌습니다.
- 이름·전화번호·이메일·주소 등 직접 식별 정보.
- 오디오 녹음 파일. 음성 인식 결과 글자만 쓰며 오디오는 저장하지 않습니다.
- 연락처, 사진, 통화 기록.

## 2. 차량 데이터와 서버로 가는 것

- 차량 상태는 **읽기만** 합니다. 차량 제어 권한(`CONTROL_`)은 요청하지 않습니다.
- 읽는 항목: 경고등, 엔진오일·변속기오일·브레이크액 수준, 타이어 저압, 워셔액 부족, 에어백 전개, 연료·배터리 잔량, 누적 주행거리.
- 읽은 값과 점검 기록은 기기 안에만 저장됩니다.
- 서버로 가는 것은 **`POST /chat` 하나**이고, 질문할 때만 갑니다.

| 서버로 가는 것 | 내용 |
|---|---|
| 질문 | 음성으로 인식한 글자 또는 키보드로 입력한 글자 |
| 앱이 만든 도구 결과 | 등급, 종합·건강·관리 점수, 구역 5개 점수, 연료·배터리 잔량(%), 켜진 경고등의 이름과 색, 부품 상태 코드, 이번 달 관리 요약 숫자(점검한 날, 연속 점검, 해결한 항목, 1위와의 차이) |
| 기기 ID | 무작위로 만든 값. 요청 횟수 제한에 씀 |

| 서버로 가지 않는 것 | |
|---|---|
| 위치·좌표 | 데모 모드의 내비 안내는 앱에 넣은 장소 목록의 좌표를 기기 안에서만 씁니다. 실제 모드는 내비 앱의 검색 화면을 엽니다 |
| 차대번호(VIN) | |
| 타이어 공기압 수치 | |
| 점검 기록 원본 | |

- 예전에는 점검 때 점수 요약을 서버에 올리고(`POST /snapshots`), 앱 사용 기록을 보내고(`/events`), 서버 순위를 불렀습니다(`/rank`, `/opponent`). **지금 앱은 이 경로를 부르지 않습니다.** 서버 코드에는 경로가 남아 있지만 앱이 쓰지 않습니다.

## 3. 보관 기간과 파기

| 데이터 | 위치 | 보관 기간 |
|---|---|---|
| 점검 기록 (실제 모드) | 기기 안 파일(`inspections_real.json`) | **90일**. 새 기록을 저장할 때 90일보다 오래된 것을 지움 |
| 점검 기록 (데모 모드) | 기기 안 파일(`inspections_demo.json`) | 실제 기록과 분리해 저장. 시나리오를 바꾸거나 날이 바뀌면 앱이 예시 값으로 새로 만듦(차량에서 읽은 값 아님) |
| 닉네임, 동의 여부, 기기 ID·비밀값 | 기기 안 | 데이터 삭제 때까지 |
| 질문 글자·차량 요약(AI 질문) | 서버에 저장하지 않음 | AI 답변을 만든 뒤 보관하지 않음(서버 코드 기준) |
| 요청 횟수 | 서버(기기 ID별 횟수) | 횟수 제한을 세는 동안만. 정확한 보관 기간은 확인 필요 |
| 예전 버전 앱이 올린 점수 요약 | 서버(Upstash Redis) | 마지막 갱신 후 **90일**, 이후 자동 만료. 지금 앱은 새로 올리지 않음 |

- 사용자가 **설정 > 내 데이터 삭제**를 누르면 확인 창을 거친 뒤 **기기 안 기록을 지웁니다.** 이어서 서버에 `DELETE /snapshots` 요청을 보냅니다. 예전에 올린 요약이 있으면 지우려는 요청이고, 없으면 아무것도 지워지지 않습니다. 그 뒤 앱이 종료되고, 다음 실행 때 동의 화면부터 다시 시작합니다.
- 서버 삭제 요청은 최대 3초만 기다리고, 실패해도 앱은 종료됩니다. 실패하면 서버의 예전 요약은 90일 뒤 만료됩니다.
- 앱을 삭제하면 기기 안 기록은 함께 삭제됩니다.

## 4. 처리 위탁과 국외 이전

| 수탁자 | 역할 | 이전 항목 | 이전 국가 | 보관 |
|---|---|---|---|---|
| Vercel Inc. | 서버 실행(API) | AI 질문 요청 본문(질문 글자, 차량 요약) | 미국 (리전 `iad1`, 2026-11-12 배포 응답으로 확인) | 요청 처리 중에만 |
| Upstash Inc. | 요청 횟수 저장, 예전 요약 저장(Redis) | 기기 ID, 요청 횟수. 예전 버전 앱이 올린 요약이 있으면 그 요약 | 미국 (리전 `iad1`, 2026-11-12 생성 때 지정) | 횟수는 확인 필요, 예전 요약은 90일 |
| Hive (The Hive AI) | AI 답변 생성 | 질문 글자, 앱이 만든 차량 요약 | 미국 | 확인 필요 |

- **확인 전 상태**: 위 세 사업자의 데이터 보관·학습 사용·서버 위치는 공식 문서로 확인 중입니다. 확인되지 않은 항목은 이 문서에 사실대로 반영합니다.
- 음성 인식·합성은 기기의 Android 시스템 엔진(`SpeechRecognizer`, `TextToSpeech`)을 씁니다. 엔진이 오디오를 기기 밖으로 보내는지는 **확인 필요**입니다.

## 5. 이용자의 권리

- **동의 3개는 모두 필수입니다.** 첫 실행 때 아래 세 가지에 모두 동의해야 앱을 쓸 수 있습니다.
  1. 차량 상태로 점수를 계산합니다.
  2. 음성 질문과 점수 요약을 서버를 거쳐 AI에 보냅니다.
  3. 대전 상대에게 닉네임·등급·점수가 보입니다.
- 하나라도 거절하면 「동의하지 않으면 서비스를 이용할 수 없어요」를 보여 주고 앱이 종료됩니다. 건너뛰기는 없습니다. 앱을 다시 켜면 동의 화면을 다시 보여 줍니다.
- **동의 철회는 설정 > 내 데이터 삭제로 합니다.** 설정에 동의를 켜고 끄는 스위치는 없습니다. 삭제 뒤 다음 실행에서 동의부터 다시 받습니다.
- 3번 동의의 「대전 상대」: 지금 버전의 대전 상대는 앱 안의 **연습 상대**(데모는 시나리오별 고정 상대)뿐입니다. 내 닉네임·등급·점수는 서버로 올라가지 않으므로 다른 이용자에게 보이지 않습니다.
- 서버에 연결되지 않으면 AI 질문은 기기 안 답(오프라인 음성)으로 대신합니다. 이때는 질문이 서버로 가지 않습니다.

## 6. 안전 관련 고지

- MOCA는 **정비 진단을 대신하지 않습니다.** 경고등이 켜지면 차량 설명서와 정비소에서 확인하세요.
- 점수와 등급은 차량이 제공한 값과 앱의 규칙으로 계산한 참고 지표입니다. 감점 숫자는 팀이 정한 설계 판단이며, 정비 규격에서 나온 값이 아닙니다.
- 데모 모드의 화면은 실제 차량 값이 아니라 예시 데이터이며, 데모 데이터를 쓰는 화면에 「데모 데이터」로 표시됩니다. 데모 모드의 점검 기록은 서버로 올라가지 않습니다.

## 부록: 실제 데이터 흐름 (구현 대조용)

```
[차량 VHAL] --(Vehicle SDK, 읽기)--> [앱: 점수 계산]
                                        |
                        기기 안 파일 (점검 기록, 실제 90일)
                                        |
                  (기기 밖으로 나가지 않음: 위치, 차대번호,
                   타이어 공기압 수치, 점검 기록 원본)

AI 질문 때만:
[마이크/키보드] --> 질문 글자 + 앱이 만든 차량 요약 + 기기 ID
                                        v
                        [Vercel API: POST /chat] ---> [Hive LLM]

데이터 삭제 때만:
[내 데이터 삭제] --> 기기 기록 삭제 --> DELETE /snapshots (예전 요약 삭제 요청) --> 앱 종료
```

- 서버 로그에는 상태 코드와 지연만 남기고 내용·키·기기 ID 원문은 남기지 않습니다(서버 README 기준).
