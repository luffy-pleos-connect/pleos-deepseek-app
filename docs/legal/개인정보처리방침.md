# MOCA 개인정보 처리방침 (초안)

시행일: 2026-11-13
서비스명: MOCA (Pleos Connect 차량용 앱)
문의: 해적단 익명 메일 (제출 시 기입)

> 이 문서는 공모전 제출용 시제품 기준입니다. 실제 개인정보 보호법상 "개인정보 처리방침" 공개 의무는 사업자에게 발생하며, 본 시제품은 그 형식을 갖춰 작성했습니다.

## 1. 수집하는 정보

| 구분 | 항목 | 수집 방법 | 목적 |
|---|---|---|---|
| 기기 식별 | 임의 생성 기기 ID(UUID v4), 기기 비밀값의 해시 | 앱이 기기 안에서 생성 | 기기별 데이터 분리, 남의 데이터 수정·삭제 방지 |
| 사용자 입력 | 닉네임(2~10자, 건너뛰면 자동 생성) | 첫 실행 화면 | 대전 상대에게 보이는 이름 |
| 차량 상태 요약 | 등급, 종합·건강·관리 점수, 카테고리 5개 점수, 점검 시각 | Vehicle SDK에서 읽어 계산 | 대전 상대 매칭, 순위 표시 |
| 음성 질문 | 인식된 질문 글자 (오디오 아님) | Android 음성 인식 | AI 답변 생성 |
| 대화 요약 | 최근 6턴의 질문·답변 글자 | 앱 → 서버 → AI | 답변 문맥 유지 |

**수집하지 않는 것**
- VIN(차대번호) 원문 — 기기 밖으로 보내지 않습니다.
- 이름·전화번호·이메일·주소 등 직접 식별 정보.
- 오디오 녹음 파일 — 음성 인식 결과 글자만 전송하며 오디오는 저장하지 않습니다.
- 위치 정보, 연락처, 사진, 통화 기록.

## 2. 차량 데이터

- 차량 상태는 **읽기만** 합니다. 차량 제어 권한(`CONTROL_`)은 요청하지 않습니다.
- 읽는 항목: 경고등 상태, 엔진오일·브레이크액 수준, 타이어 저압·공기압, 배터리 잔량·충전 상태, 주행거리.
- 읽은 원본값은 기기 안 데이터베이스에만 저장되고, 서버로는 **점수 요약(0~100 정수 5개 + 등급)** 만 보냅니다.

## 3. 보관 기간과 파기

| 데이터 | 위치 | 보관 기간 |
|---|---|---|
| 점검 기록 | 기기 안(SQLite) | 사용자가 삭제할 때까지 |
| 차량 요약 | 서버(Upstash Redis) | 마지막 갱신 후 **90일**, 이후 자동 만료 |
| 음성 질문·대화 | 서버에 저장하지 않음 | AI 응답 생성 후 폐기 |
| 기기 ID·비밀값 해시 | 서버 | 요약과 같은 90일 |

- 사용자가 **설정 > 내 데이터 삭제**를 누르면 기기 기록이 0건이 되고 서버 요약도 즉시 삭제됩니다(`DELETE /snapshots`, 기기 비밀값 확인 필요).
- 앱을 삭제하면 기기 안 기록은 함께 삭제됩니다. 서버 요약은 90일 뒤 만료됩니다.

## 4. 처리 위탁과 국외 이전

| 수탁자 | 역할 | 이전 항목 | 이전 국가 | 보관 |
|---|---|---|---|---|
| Vercel Inc. | 서버 실행(API) | 요청 본문(점수 요약, 질문 글자) | 미국 (리전 설정 확인 필요) | 요청 처리 중에만 |
| Upstash Inc. | 요약 저장(Redis) | 기기 ID, 닉네임, 점수 요약 | 확인 필요 | 90일 |
| Hive (The Hive AI) | AI 답변 생성 | 최근 6턴 질문·답변, 점수 요약 | 미국 | 확인 필요 |

- **확인 전 상태**: 위 세 사업자의 데이터 보관·학습 사용·서버 위치는 공식 문서로 확인 중입니다. 확인되지 않은 항목은 이 문서에 사실대로 반영합니다. 확인되지 않으면 해당 데이터를 보내지 않는 대안을 씁니다.
- 음성 인식·합성은 기기의 Android 시스템 엔진(`SpeechRecognizer`, `TextToSpeech`)을 씁니다. 엔진이 오디오를 기기 밖으로 보내는지는 확인 중이며, 확인 전에는 **오프라인 인식 우선** 옵션을 켭니다.

## 5. 이용자의 권리

- 설정에서 언제든 데이터 삭제를 요청할 수 있습니다.
- 동의를 거부하면 앱은 **오프라인 음성**(기기 안 의도 인식)과 **연습 상대 대전**만 제공합니다. 점검·점수·상태관리는 서버 없이 동작합니다.
- 동의 항목: ① 차량 상태로 점수 계산 ② 음성 질문과 점수 요약을 서버를 거쳐 AI에 전송 ③ 대전 상대에게 닉네임·등급·카테고리 점수 표시

## 6. 안전 관련 고지

- MOCA는 **정비 진단을 대신하지 않습니다.** 경고등이 켜지면 차량 설명서와 정비소에서 확인하세요.
- 점수와 등급은 차량이 제공한 값과 앱의 규칙으로 계산한 참고 지표입니다.
- 데모 모드의 화면은 실제 차량 값이 아니라 예시 데이터이며, 모든 화면에 "데모 데이터"로 표시됩니다.

## 부록: 실제 데이터 흐름 (구현 대조용)

```
[차량 VHAL] --(Vehicle SDK, 읽기)--> [앱: 점수 계산]
                                        |
                        기기 안 SQLite (점검 기록, 원본값)
                                        |
                        점수 요약만 (등급·5개 점수·시각)
                                        v
                        [Vercel API] ---> [Upstash Redis]  (90일 TTL)
                                        |
                                        +--> [Hive LLM]  (질문 6턴 + 점수 요약)

[마이크] --(Android SpeechRecognizer)--> 글자 --> 위와 같은 경로
[TTS] <-- 답변 글자 -- [앱]
```

- 서버 로그에는 상태 코드와 지연만 남기고 내용·키·기기 ID 원문은 남기지 않습니다.
