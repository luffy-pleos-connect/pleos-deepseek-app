# 서버를 올리고 앱에서 확인한 기록 (2026-11-12)

결론: 서버를 `https://moca-server.vercel.app` 로 올렸고, 그 주소를 넣은 release APK 로 음성 답과 점검 요약 올리기·지우기를 에뮬레이터에서 확인했다. 확인하다 찾은 문제 4개를 고쳤다. 앱 화면에서 다른 사용자와 대전하는 모습은 보지 못했다.

## 올린 것

| 항목 | 값 |
|---|---|
| 주소 | `https://moca-server.vercel.app` (`/api/chat`, `/api/opponent`, `/api/snapshots`) |
| Vercel 프로젝트 | `moca-server`, 리전 `iad1`, Node 24 |
| 올린 파일 | `api/*.mjs` 3개, `core.mjs`, `http-util.mjs`, `validate.mjs`, `store-redis.mjs`, `vercel-entry.mjs`, `seeds.json` |
| 저장소 | Vercel Marketplace 의 Upstash for Redis 무료 요금제 `moca-redis`, 리전 `iad1` |
| 환경 변수 | `HIVE_API_URL`, `HIVE_API_KEY`, 연동이 넣은 `KV_REST_API_URL`·`KV_REST_API_TOKEN` 등 |

첫 배포에서 올라간 9개 파일의 SHA-1 이 저장소 파일과 같은 것을 확인했다.

## 서버를 직접 불러 본 결과

| 무엇을 | 결과 |
|---|---|
| 값을 넣기 전 `GET /api/opponent`, `POST /api/chat` | 500 `not_configured` |
| `GET /api/opponent` | 200, 시드 상대 |
| 기기 A 가 요약을 올림(`POST /api/snapshots`, `isDemo=false`) | 200 `{"ok":true}` |
| 기기 B 가 상대를 40번 뽑음 | 기기 A 의 요약이 3번, 시드 11종 |
| 틀린 비밀값으로 삭제 | 403 `secret_mismatch` |
| 맞는 비밀값으로 삭제 | 204 |
| 삭제 뒤 기기 B 가 10번 뽑음 | 기기 A 의 요약 0번 |
| `POST /api/chat` (ABS 경고등 질문) | 200, 3.5초, 한국어 한 문장 |

시험에 쓴 요약은 위 순서대로 지웠다.

## 확인하다 찾아 고친 것

1. **연동이 넣는 환경 변수 이름이 달랐다.** Vercel 의 Upstash 연동은 `KV_REST_API_URL`·`KV_REST_API_TOKEN` 으로 넣는다. 진입부가 두 이름을 다 받게 했다.
2. **서버 답이 문장 중간에서 끊겼다.** 토큰 한도 300 에 모델의 추론 토큰이 들어가서다. Hive 를 직접 3번 불러 2번 재현했다(끊겨도 `finish_reason` 은 `stop`). 한도를 1000 으로 올렸고, 한도에 닿으면 끝난 문장까지만 보낸다. 고친 뒤 같은 질문 5번 모두 문장으로 끝났다(5.3~7.3초).
3. **빨간 경고등인데 정차 안내가 빠진 답이 나왔다.** 모델에게 부탁만 하고 있었다. 앱이 차의 값을 읽은 답에 정차 안내가 없으면 첫 문장에 붙인다. 답이 비었을 때 모델의 추론문(영어)을 보여 주던 것도 기기 안의 답으로 바꿨다.
4. **앱이 점검 요약을 올리거나 지우지 않았다.** 서버에는 있었고 앱에는 부르는 코드가 없었다. 대전 공개에 동의하면 점검 뒤 요약을 올리고, 「내 데이터 삭제」 때 서버 요약도 지운다.

## 확인하지 못한 것

- 앱 화면에서 다른 사용자와 대전하는 모습. 이 에뮬레이터의 실제 값으로는 등급이 나오지 않고, 데모 모드는 정해진 상대와 겨룬다.
- 올린 서버에서 횟수 제한(429)에 닿는 것. 테스트로만 확인했다.
- 주행 중 답 길이 제한. 주행 상태를 만들 수 없다.
- Vercel Hobby 요금제는 비상업용이다. 상금이 있는 공모전에 써도 되는지는 확인하지 않았다.
