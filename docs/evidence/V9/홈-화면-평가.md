# 홈 화면 평가 (2026-11-12)

홈 캡처를 서로 다른 모델 셋(Claude Haiku, Sonnet, Opus)에게 보여 주고 두 가지를 물었다. 평가자는 그림 파일만 받았고, 어느 쪽이 고친 화면인지 듣지 못했다. 사람 평가가 아니다.

- 판독: 데모 D3 홈 캡처 한 장만 보고 「등급, 가장 급한 문제, 누를 단추」를 말한다.
- 전후 비교: 고치기 전 홈(`홈-고치기-전.png`, 2026-11-10 화면)과 지금 홈을 「가」「나」로만 받아 운전자에게 더 나은 쪽을 고른다. 평가자마다 가·나 순서를 바꿨다.

## 1차 (고치기 전의 지금 홈)

| 평가자 | 판독 | 전후 비교 |
|---|---|---|
| Haiku | 셋 다 맞음 (B, ABS 경고등, 가까운 정비소 안내) | 지금 홈 |
| Sonnet | 셋 다 맞음 | **고치기 전 홈** |
| Opus | 셋 다 맞음 | 지금 홈 |

전후 비교가 2 대 1 이라 통과하지 못했다. 셋이 같이 짚은 것은 이렇다.

- 왼쪽 카드에 작은 글자가 많다(남은 점수, 순위, 건강·관리, 「주의 2」, 날짜).
- 등급은 B 인데 고리가 빨강이라 눈이 고리와 「주의 2」로 먼저 간다. 정작 급한 「가장 먼저 할 일」 칸은 덜 눈에 띈다.
- 「주의 2」가 무엇을 세는지 알 수 없다. 목록의 「위험·주의」와 낱말이 겹친다.
- 위험한 줄(제동·조향)이 작은 점 하나로만 표시된다.

## 고친 것

- 건강·관리·마지막 점검일을 작은 글자 한 줄로 모았다.
- 「주의 2」를 「경고등 2개 켜짐」으로 바꾸고 「가장 먼저 할 일」 칸으로 옮겼다. 켜진 것이 없으면 줄을 숨긴다.
- 고리는 점수만 나타낸다(빨강을 쓰지 않는다). 위험은 「가장 먼저 할 일」의 글자와 위험한 카테고리 줄의 낱말·점수를 빨강으로 적어 알린다.

## 2차 (고친 홈, 새 평가자)

| 평가자 | 판독 | 전후 비교 |
|---|---|---|
| Haiku | 셋 다 맞음 | 지금 홈 |
| Sonnet | 셋 다 맞음 | 지금 홈 |
| Opus | 셋 다 맞음 | 지금 홈 |

판독 3 중 3, 전후 비교 3 중 3.

2차 뒤에 하나 더 고쳤다. 「−50」이 깎인 점수인지 남은 점수인지 헷갈린다는 지적이 있어 「50점 감점」으로 바꿨다. 이 문구로는 다시 평가하지 않았다.

## 남은 지적 (고치지 않은 것과 까닭)

- 순위·건강·관리·날짜를 홈에서 빼라는 의견(셋 중 둘). 건강·관리·남은 점수와 오늘의 순위는 홈에 두기로 한 기능이라 남겼다. 작은 글자로 낮췄다.
- 고리 색. 1차에서는 「빨강이라 위험해 보인다」, 2차에서는 「위험이 있는데 파랑이다」로 의견이 갈렸다. 고리는 점수만 나타내는 것으로 정했다.
- 해결 단추가 짙은 회색이라 덜 눈에 띈다는 의견. 디자인 시스템의 강조 단추 그대로다. 바꾸지 않았다.
- 「경고등 2개 켜짐」인데 이름이 나온 것은 하나라는 의견. 나머지는 상세와 「차에게 묻기」에서 이름이 나온다.
