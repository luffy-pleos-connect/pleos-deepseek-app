## 1차 발송 (11/14 23:30 전)

**받는 사람**: 공모전 접수 메일 (공식 사이트 `/guide/submission` 에서 확인한 주소)
**참조(CC)**: 팀원 전원
**제목**:
```
[차량용 앱 개발 공모전] 해적단_대표자명
```
> 팀명과 대표자명은 사람이 확정해 채운다. 개인이면 성명.

**본문**:
```

[3] 참가 형태: 팀 (팀원 N명, 전원 동의·서명 첨부)
[4] 한 줄 소개: 차가 알려 주는 부품 상태, 점수와 등급으로 키우는 관리 파트너

■ 첨부
1. 참가신청서 및 기획서 (공식 양식, 01~04장)
2. 서명본 (팀원 전원)
3. MOCA_release.apk (서명된 release)
4. README.md
5. 별지_MOCA.pdf

8. 숏폼 링크: (팀 계정 게시 링크 — 02-8)

■ 실행 환경
- Pleos Connect 에뮬레이터 (API 34, Pleos Connect v2.1.0)

- 서버: (Vercel 주소)

■ 실연동 상태 (사실대로)
Vehicle SDK 연동 코드 구현 완료, 에뮬레이터에서 배터리 SOC 실값(100) 수신과

Virtual Console의 DDS 브리지 제약으로 확인하지 못했습니다. 데모 화면은 모두
"데모 데이터"로 표시했습니다.
```

## 발송 전 체크 (사람)

- [ ] 제목 형식이 `[차량용 앱 개발 공모전] 팀명_대표자명` 인가 (SUB-01)
- [ ] 팀원 전원을 **CC**에 넣었는가 (SUB-02)
- [ ] 팀원 전원 **서명본**이 첨부됐는가 (CC만으로는 동의 대체 불가)

- [ ] 깨끗한 에뮬레이터에서 설치·실행을 다시 확인했는가 (SUB-04)

- [ ] 수정제출은 제목에 `[수정제출]` + 전체 재첨부 (SUB-06)
