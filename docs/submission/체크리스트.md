## 실행 환경 (SUB-04 대비)

```bash
# 에뮬레이터 (창 없는 모드 — 이 맥에서 창 모드는 QEMU가 멈춘다)
export ANDROID_HOME="$HOME/Library/Android/sdk"
"$ANDROID_HOME/emulator/emulator" -avd Pleos_Connect_v2.1.0 \
  -no-snapshot-load -gpu host -no-audio -no-window &

# 서버 (로컬)
cd server && HIVE_API_KEY=... node local.mjs

# APK 설치
"$ANDROID_HOME/platform-tools/adb" install apk/해적단_MOCA_release.apk
"$ANDROID_HOME/platform-tools/adb" shell am start -n ai.moca.app/.MainActivity
```

- release 빌드의 서버 주소는 빌드할 때 넣는다(`-Pmoca.serverBaseUrl=`). 기본은 빈 값이고, 비어 있으면 앱은 서버를 부르지 않고 오프라인 음성(기기 안의 답)으로 동작한다. 앱이 서버로 부르는 것은 AI 질문(`POST /chat`)과 데이터 삭제 때의 `DELETE /snapshots` 뿐이다.
- **새 APK 를 빌드할 때 우리 서버 주소를 넣었는지, 빌드한 뒤 APK 안의 주소 문자열로 확인한다.** 옛 빌드(2026-11-10)에는 우리 것이 아닌 주소가 들어 있었다. 옛 APK 를 따로 갖고 있다면 제출하지 않는다.
