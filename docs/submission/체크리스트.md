## 실행 환경 (SUB-04 대비)

```bash
# 에뮬레이터 (창 없는 모드 — 이 맥에서 창 모드는 QEMU가 멈춘다)
export ANDROID_HOME="$HOME/Library/Android/sdk"
"$ANDROID_HOME/emulator/emulator" -avd Pleos_Connect_v2.1.0 \
  -no-snapshot-load -gpu swiftshader_indirect -no-audio -no-window &

# 서버 (로컬)
cd server && HIVE_API_KEY=... node local.mjs

# APK 설치
"$ANDROID_HOME/platform-tools/adb" install apk/해적단_MOCA_release.apk
"$ANDROID_HOME/platform-tools/adb" shell am start -n ai.moca.app/.MainActivity
```

- release APK의 서버 주소는 `https://moca.vercel.app`이다. **Vercel 배포 전에는 서버 연결이 실패**하고 앱은 오프라인 음성·연습 상대로 동작한다(이것도 정상 동작이므로 SUB-04 시험에 포함).
