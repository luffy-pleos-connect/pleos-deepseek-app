> 2026-11-14 에 새 구조(상태관리 · 보이스챗 · 대전하기)에 맞춰 고쳤다. 옛 앱으로 찍은 파일(`시연영상_MOCA_3분.mp4`, `시연영상_MOCA_전체.mp4`)은 이 대본과 다르다. **다시 찍어야 한다.**

- 해상도 1080p 이상, 30fps, H.264

## 녹화 전 준비

1. 에뮬레이터: `-gpu host -no-audio -no-window` (`-gpu swiftshader_indirect` 는 주행 화면 앱이 되풀이해 죽어 터치가 전달되지 않는다. README 참고)
2. 앱: debug 빌드 설치, **데이터를 지운 첫 실행 상태**로 시작(동의 화면 장면용). 서버 장면은 로컬 서버를 켜 둔다(`cd server && HIVE_API_KEY=... node local.mjs`, 에뮬레이터에서 닿는 방법은 미리 확인)
3. 시스템: 상태바 알림 지우기, 시계는 그대로, GNB 앱 서랍이 열려 있으면 닫기
4. 터치 표시: `adb shell settings put system show_touches 1`
5. 녹화: `ffmpeg -f avfoundation -framerate 30 -i "1:0" -vf "scale=1920:-2" -c:v libx264 -preset medium -crf 18 out.mp4`
   - 화면 캡처만 필요하면 `adb shell screenrecord --size 1920x1080 --bit-rate 8M /sdcard/demo.mp4`
6. 장면 순서: 동의(실제 모드) → 설정에서 데모 모드 켜고 D3 선택 → 앱을 다시 켜서 앱 시작 화면

## 정직 표기 (반드시)

- 영상 어디에도 "실차 검증"이라고 쓰지 않는다. "에뮬레이터"를 명시한다.
- 경고등 색 정수 미확인을 숨기지 않는다. 0:20 장면 자막에 "경고등 색 정수는 미확인"을 넣거나, 2:48 마무리에 한 줄로 넣는다.
- 데모 화면에는 "데모 데이터" 배지가 화면에 보이게 한다(자막으로 가리지 않는다).
- 2D 자동차 그림은 자리표시 그림이다. 디자이너 그림으로 바꾼 뒤 찍는다면 그 그림을 쓴다(확인 필요).
- 내비 장면은 **데모 모드(앱에 넣은 장소 목록의 좌표로 안내)** 임을 말한다. 실제 모드는 내비의 검색 화면을 연다.
- 대전 상대는 연습 상대이고, 월간랭킹은 연습 상대 12명과 나다. 실제 사용자 순위가 아니다.
