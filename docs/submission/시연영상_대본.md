# 시연 영상 대본 (D-09) — ≤3:00, 대표 이야기 D3

- 해상도 1080p 이상, 30fps, H.264
- 자막 100%, 질문·답 음성 모두 들려야 함(MV-01)
- 2초 넘는 정적 화면 0
- 실명·계정·알림 노출 0

## 녹화 전 준비

1. 에뮬레이터: `-gpu swiftshader_indirect -no-audio -no-window` (이 맥의 유일한 부팅 방법)
2. 앱: debug 빌드 설치, **데모 모드 OFF**로 시작(실제 프로필 장면용)
3. 시스템: 상태바 알림 지우기, 시계는 그대로, GNB 앱 서랍이 열려 있으면 닫기
4. 터치 표시: `adb shell settings put system show_touches 1`
5. 녹화: `ffmpeg -f avfoundation -framerate 30 -i "1:0" -vf "scale=1920:-2" -c:v libx264 -preset medium -crf 18 out.mp4`
   - 화면 캡처만 필요하면 `adb shell screenrecord --size 1920x1080 --bit-rate 8M /sdcard/demo.mp4`

## 자막 규칙

- 하단 안전 영역 20% 비우지 않아도 됨(영상은 16:9 전체 사용)

- 한 줄 20자 이내, 최대 2줄
- 등장·퇴장 300ms 크로스페이드

## 정직 표기 (반드시)

- 영상 어디에도 "실차 검증"이라고 쓰지 않는다. "에뮬레이터"를 명시한다.
- 경고등 색 정수 미확인을 숨기지 않는다. 0:10 장면 자막에 "경고등 색 정수는 미확인"을 넣거나, 2:35 마무리에 한 줄로 넣는다.
- 데모 화면에는 "데모 데이터" 배지가 화면에 보이게 한다(자막으로 가리지 않는다).
