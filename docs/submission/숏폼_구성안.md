# 숏폼 구성안 (D-10) — 30~60초 세로

- 1080×1920 세로, 첫 2초 훅
- 자막 ≥60px, 위 15%·아래 20%는 안전 영역으로 비움
- 게시 문구: `#HMG차량용앱개발공모전` + 2개
- 팀 계정으로 11/14까지 게시, 링크를 02-8에 기입

## 컷 구성 (30초판)

| 시간 | 화면 | 자막 | 비고 |
|---|---|---|---|
| 0:00–0:02 | 등급 B → A로 바뀌는 순간 클로즈업 | **"경고등 하나로\n등급이 올랐다"** | 첫 2초 훅. 숫자 크게 |
| 0:02–0:08 | 홈 (세로 크롭) | "차가 알려 주는\n부품 상태" | 등급·종합 강조 |
| 0:08–0:16 | 보이스 답변 장면 | "이 경고등 뭐야?"\n→ "안전한 곳에\n정차한 뒤 점검" | 질문 자막 + 답 자막 |

## 32초판 (제작 완료: `숏폼_MOCA_32s.mp4`)

스틸 4장을 8초씩 이어 붙인 판. 자막·음악 없음, H.264 1080×1920 30fps.

| 시간 | 화면 |
|---|---|
| 0:00–0:08 | 등급 B→A (`shortform_1.png`) |
| 0:08–0:16 | 홈 (`shortform_2.png`) |
| 0:16–0:24 | 상태관리 상세 (`shortform_3.png`) |
| 0:24–0:32 | 대전 역전승 (`shortform_4.png`) |

## 제작 방법

1. 원본: `docs/evidence/G2/screens/*.png` + 시연 영상 소스
2. 세로 크롭: 2560×1440 → 1080×1920 (좌우 크롭 후 상하 패딩, 또는 앱 창 영역만 크롭)
3. 자막: ffmpeg `drawtext` + Asta Sans 또는 Apple SD Gothic Neo, 60px 이상
4. 안전 영역: 위 288px, 아래 384px 비움
5. 출력: H.264, 1080×1920, 30fps

### ffmpeg 예 (정지 이미지로 `숏폼_MOCA_32s.mp4` 만들기)

```bash
ffmpeg -y \
 -loop 1 -framerate 30 -t 8 -i shortform_1.png \
 -loop 1 -framerate 30 -t 8 -i shortform_2.png \
 -loop 1 -framerate 30 -t 8 -i shortform_3.png \
 -loop 1 -framerate 30 -t 8 -i shortform_4.png \
 -filter_complex "\
[0:v]scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,setsar=1,fps=30[v0];\
[1:v]scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,setsar=1,fps=30[v1];\
[2:v]scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,setsar=1,fps=30[v2];\
[3:v]scale=1080:1920:force_original_aspect_ratio=decrease,pad=1080:1920:(ow-iw)/2:(oh-ih)/2:color=black,setsar=1,fps=30[v3];\
[v0][v1][v2][v3]concat=n=4:v=1:a=0[out]" \
 -map "[out]" -c:v libx264 -profile:v high -pix_fmt yuv420p -r 30 \
 -movflags +faststart 숏폼_MOCA_32s.mp4
```

자막을 넣으려면 각 입력 뒤에 `drawtext`(Asta Sans 또는 Apple SD Gothic Neo, 60px 이상)를 덧붙인다.
