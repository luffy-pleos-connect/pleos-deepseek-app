# 숏폼 구성안 — 30초 세로

- 1080×1920 세로, 소리 없음, H.264 30fps. 위 15%, 아래 20%는 비운다.
- 파일: `docs/submission/숏폼_MOCA_30s.mp4`(보기용 압축본) — 2026-11-15 에 HyperFrames 로 다시 만든 홍보판이다. 원본·소스는 `promo/`(만드는 법은 `promo/SPEC.md`, 렌더는 `npx hyperframes render`), 원본 렌더는 GitHub 릴리스의 `MOCA_short_30s.mp4`.
- 실제 구성은 아래 컷 표가 아니라 `promo/SPEC.md` 의 장면표를 따른다(자막+음악+효과음, «데모» 글자 없음).
- 화면은 에뮬레이터에서 실제로 누르며 찍은 녹화와 캡처다(데모 D3). 앱 창에서 필요한 부분만 잘라 넣는다.
- 게시(팀 계정, 문구, 링크 기입)는 사람이 한다.

## 컷

| 시간 | 화면 | 큰 글자 | 작은 글자 |
|---|---|---|---|
| 0:00–0:03 | 앱 시작 화면(데모 D3, B · 75, 빨간 경고등 ABS) | 경고등이 켜졌다. 얼마나 급한 걸까? | |
| 0:03–0:09 | 상태관리의 2D 그림(구역 색)과 구역 카드, ABS 상세의 [정비소 찾기] | 점수 낮은 구역부터, 고칠 방법까지 | 앱을 켜면 점검은 끝나 있다 |
| 0:09–0:16 | 보이스챗: 「가까운 정비소 안내해줘」 → 확인 카드 → [안내 시작] → 내비 안내(녹화, 빠르게) | 말로 묻고, 확인하면 내비가 안내한다 | 데모 모드: 장소 목록의 좌표로 안내 |
| 0:16–0:22 | 대전하기: 2D 충돌 연출과 「이 차만큼 관리하려면」 | 진 구역은 무엇을 고칠지 알려 준다 | 연습 상대와의 대전 |
| 0:22–0:26 | [ABS 해결 (데모)] 뒤 A · 83, 월간랭킹 9위 | 고치면 등급이 오른다 B → A | 월간랭킹은 연습 상대 12명과 나 |
| 0:26–0:30 | 끝 화면 | MOCA + 한 줄 소개 | 화면은 Pleos Connect 에뮬레이터의 데모 시나리오입니다 |

- 대전 컷은 두 차가 부딪쳐 진 쪽이 부서지는 3D 장면을 쓴다.
- 2D 자동차 그림이 자리표시 그림이면 디자이너 그림으로 바뀐 뒤에 찍는다(확인 필요).

## 만드는 법

```bash
# 앱을 막 설치한 상태(동의 전)에서 시작한다. 장면별 녹화 → 3분 시연 영상 → 30초 숏폼
python3 tools/video/e2e_v12.py <결과 폴더> record
python3 tools/video/e2e_v12.py <결과 폴더> compose   # <결과 폴더>/MOCA_시연영상.mp4
python3 tools/video/e2e_v12.py <결과 폴더> short     # <결과 폴더>/MOCA_숏폼_30s.mp4
```

`tools/video/e2e.py`, `e2e_video.py`, `e2e_short.py` 는 옛 화면 기준이라 지금 앱에서는 돌아가지 않는다. 새 화면은 `e2e_v12.py` 를 쓴다. Pillow 가 필요하다.

에뮬레이터는 `-gpu host` 로 띄운다. ffmpeg 와 Apple SD Gothic Neo 글꼴(macOS)이 필요하다.
