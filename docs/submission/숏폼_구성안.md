- 자막 ≥60px, 위 15%·아래 20%는 안전 영역으로 비움
- 게시 문구: `#HMG차량용앱개발공모전` + 2개
- 팀 계정으로 11/14까지 게시, 링크를 02-8에 기입

## 제작 방법

1. 원본: `docs/evidence/G2/screens/*.png` + 시연 영상 소스
2. 세로 크롭: 2560×1440 → 1080×1920 (좌우 크롭 후 상하 패딩, 또는 앱 창 영역만 크롭)
3. 자막: ffmpeg `drawtext` + Asta Sans 또는 Apple SD Gothic Neo, 60px 이상
4. 안전 영역: 위 288px, 아래 384px 비움
5. 출력: H.264, 1080×1920, 30fps

### ffmpeg 예 (정지 이미지로 15초판)

```bash
ffmpeg -loop 1 -i home_final.png -t 5 \
  -vf "scale=-2:1920,crop=1080:1920,drawtext=fontfile=/System/Library/Fonts/AppleSDGothicNeo.ttc:text='차가 알려 주는 부품 상태':fontsize=72:fontcolor=white:box=1:boxcolor=black@0.6:boxborderw=24:x=(w-text_w)/2:y=1500" \
  -c:v libx264 -pix_fmt yuv420p -r 30 clip1.mp4
```
