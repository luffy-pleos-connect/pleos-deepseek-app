# 숏폼 구성안 — 30초 세로

- 1080×1920 세로, 소리 없음, H.264 30fps. 위 15%, 아래 20%는 비운다.
- 파일: `docs/submission/숏폼_MOCA_30s.mp4` (2026-11-12, 지금 화면으로 다시 만듦)
- 화면은 에뮬레이터에서 실제로 누르며 찍은 녹화와 캡처다. 앱 창에서 필요한 부분만 잘라 넣었다.
- 게시(팀 계정, 문구, 링크 기입)는 사람이 한다.

## 만드는 법

```bash
# 1. 에뮬레이터에서 처음부터 끝까지 누르며 장면별로 녹화한다(10분쯤)
python3 tools/video/e2e.py <결과 폴더>
# 2. 긴 시연 영상(자막 포함)
uv run --with pillow python tools/video/e2e_video.py <결과 폴더> 시연영상_MOCA_전체.mp4
# 3. 3분 안쪽 시연 영상과 숏폼
uv run --with pillow python tools/video/e2e_short.py <결과 폴더> 시연영상_MOCA_3분.mp4 숏폼_MOCA_30s.mp4
```

에뮬레이터는 `-gpu host` 로 띄운다. ffmpeg 와 Apple SD Gothic Neo 글꼴(macOS)이 필요하다.
