## 7. 이번 세션에서 고친 실제 결함 (기록)

정직성·정확성에 직결된 것만:
1. **없는 등급을 만들어 표시** — 측정 항목이 3개 미만인데 "A 85"를 표시. `MIN_MEASURED_CATEGORIES=3` 규칙 + 미지원 항목 명시로 수정.
2. **Hive tool_calls 시 502** — `content`가 빈 문자열인데 502를 반환. `tool_calls`·`reasoning_content` 처리 추가.
3. **Pleos 리스너 스레드 위반** — `CalledFromWrongThreadException`. `Handler.post`로 메인 전달.
4. **DS Card 오용** — `android:background="@style/..."` → `InflateException`. `style=` 속성으로 수정.
5. **AppCompat 테마 충돌** — `AppCompatActivity` + `Theme.PleosConnect` 크래시. `FragmentActivity`로 변경.
6. **Fragment 겹침** — 탭 전환이 안 됨. `hide/show` → `replace`.
7. **JVM 테스트에서 org.json 스텁** — 실제 구현 의존성 추가.
8. **숫자 잘림** — 종합 73이 "7"로 표시. `match_parent` + `maxLines=1`.
9. **공식 양식 DOCX에 주최 측 담당자 실명** — 메타데이터에서 `MOCA Team`으로 덮어씀.
