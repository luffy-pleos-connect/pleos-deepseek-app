# 평가 조작·볼 곳 신고

이 문서는 「MOCA 기능별 평가기준표」 v2 의 2장에 따라, 평가자가 앱을 조작하고 값을 읽을 때 쓸 노드의 `resource-id` 를 신고한다. 적은 id 는 모두 `app/app/src/main/res/layout` 의 `@+id` 다. 코드로만 만드는 줄(순위 목록의 한 줄, 대전 라운드 칸)은 부모 id 와 가려내는 규칙을 적었다.

- 패키지: `ai.moca.app`
- 화면 전환은 `MainActivity` 가 Fragment 를 교체하는 방식이다(`app/app/src/main/java/ai/moca/app/MainActivity.kt` 의 `show()`).
- 아래 탭은 홈 `tabHome`, 상세 `tabStatus`, 차에게 묻기 `tabVoice`, 순위·대전 `tabBattle`, 설정 `tabSettings` 다(`activity_main.xml`).
- 점검은 앱을 열면 돈다. 점검 결과를 보려면 홈으로 간다. 누르는 노드는 없다.

| 조작-1 | 데모 켜기: `ai.moca.app:id/tabSettings` → `ai.moca.app:id/settingsGroupDemo` → 스위치 `ai.moca.app:id/switchDemo` 를 눌러 ON. 데모 끄기: 같은 경로로 스위치를 OFF. 데모 패널은 그룹을 누르기 전에는 숨는다(`SettingsFragment.kt` `showGroup`). 스위치를 바꾸면 액티비티가 다시 만들어진다(`SettingsFragment.kt` `demo.setOnCheckedChangeListener`) | `ai.moca.app:id/tabSettings` → `ai.moca.app:id/settingsGroupDemo` → `ai.moca.app:id/switchDemo` |
| 조작-2 | 데모 시나리오 D0~D6: 조작-1 로 데모를 켠 뒤 `ai.moca.app:id/settingsGroupDemo` 를 누르고 `ai.moca.app:id/scenarioD0` … `ai.moca.app:id/scenarioD6` 가운데 하나를 누른다(`SettingsFragment.kt` `scenarioButtons`). 시나리오 묶음은 데모가 켜져 있을 때만 보인다. 누르면 액티비티가 다시 만들어진다 | `ai.moca.app:id/tabSettings` → `ai.moca.app:id/settingsGroupDemo` → `ai.moca.app:id/scenarioD0` ~ `ai.moca.app:id/scenarioD6` |
| 조작-3 | 홈: `ai.moca.app:id/tabHome`. 결과가 보이는 화면: 앱을 연다. 누르는 노드 없음(홈에 등급과 종합이 있다). 상태관리(상세): `ai.moca.app:id/tabStatus`. ## 볼 곳 신고

| 볼 곳 이름 | 노드 (resource-id) |
|---|---|
| 홈.등급 | `ai.moca.app:id/gradeValue` |
| 홈.종합 | `ai.moca.app:id/totalValue` (글자 형식 `종합 %1$s`, `strings.xml` `home_total_value`) |
| 홈.건강 | `ai.moca.app:id/healthValue` (형식 `건강 %1$s`) |
| 홈.관리 | `ai.moca.app:id/careValue` (형식 `관리 %1$s`) |
| 홈.남은점수 | `ai.moca.app:id/gradeHint`. 빨간 경고등이 있으면 `빨간 경고등을 해결하면 …` 이고, 아니면 `A까지 5점` 형식이다(`HomeFragment.kt` `renderGrade`) |
| 홈.마지막점검 | `ai.moca.app:id/lastInspection` |
| 홈.순위 | `ai.moca.app:id/rankText`. 형식 `오늘 %1$d위 · %2$d명 중 · 연습 순위`(`strings.xml` `home_rank_line`) |
| 점검.결과 | `ai.moca.app:id/gradeValue` 와 `ai.moca.app:id/totalValue`. 결과가 보이는 화면은 홈이다 |
| 점검.카테고리 | `ai.moca.app:id/categoryList` 안의 `ai.moca.app:id/catPowerScore`, `ai.moca.app:id/catBrakeScore`, `ai.moca.app:id/catTireScore`, `ai.moca.app:id/catElectricScore`, `ai.moca.app:id/catSafetyScore`. 상태 낱말은 `catPowerStatus`, `catBrakeStatus`, `catTireStatus`, `catElectricStatus`, `catSafetyStatus` |
| 상태.카드 | `ai.moca.app:id/statusCategoryList` 안의 `statusPowerStatus`/`statusPowerScore`, `statusBrakeStatus`/`statusBrakeScore`, `statusTireStatus`/`statusTireScore`, `statusElectricStatus`/`statusElectricScore`, `statusSafetyStatus`/`statusSafetyScore`. 각 id 앞에 `ai.moca.app:id/` 가 붙는다 |
| 상태.상세 | 고른 카테고리의 `ai.moca.app:id/detailValues`, `ai.moca.app:id/detailDeductions`, `ai.moca.app:id/detailAdvice`. 제동·조향은 `ai.moca.app:id/statusBrake`, 타이어는 `ai.moca.app:id/statusTire` 를 누른 뒤에 읽는다 |
| 상태.추이 | `ai.moca.app:id/trendGraph`. 점수 글자는 캔버스에 그린다(`TrendGraphView.kt` `onDraw`). `text` 속성에는 날짜가 없다. 점이 2개 미만이면 `ai.moca.app:id/trendEmpty` 가 보인다 |
| 보이스.답 | `ai.moca.app:id/answerText` |
| 보이스.상태 | `ai.moca.app:id/voiceState` |
| 보이스.질문 | 알아들은 질문을 남겨 두는 노드는 없다. 보내기 전의 글자는 `ai.moca.app:id/questionInput` 이고, 추천 질문 글자는 `ai.moca.app:id/suggestion1` ~ `ai.moca.app:id/suggestion4` 에 있다 |
| 대전.상대 | `ai.moca.app:id/opponentName`, `ai.moca.app:id/opponentScore` |
