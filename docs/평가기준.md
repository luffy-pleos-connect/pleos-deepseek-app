# MOCA 평가기준

작성 2026-11-11 · 대상 앱 `ai.moca.app` (Pleos Connect, Vehicle SDK 2.3.2)

이 문서는 **판정자가 재량을 넣을 칸을 만들지 않는 것**을 목적으로 한다. 판정 결과는 `통과` / `실패` / `해당없음` 셋 중 하나이고, 기대값은 화면에 보이는 문자열이나 숫자로 적는다.

## 0. 이 문서를 읽는 방법

### 0-1. 증거 등급

이 문서의 모든 기술적 주장에는 등급을 붙인다. 등급이 없으면 판정 근거로 쓰지 않는다.

| 등급 | 뜻 | 확인 방법 |
|---|---|---|
| `[실측]` | 이 맥에서 명령을 돌려 출력으로 확인함 | 명령과 출력을 문서에 적음 |
| `[바이너리]` | AAR `javap` 로 타입·시그니처를 확인함 | 클래스 경로를 적음 |
| `[문서-스니펫]` | Pleos 공식 문서의 **검색 스니펫**에 문장이 있음 | URL과 스니펫 원문을 적음 |
| `[문서-미확인]` | 문서 페이지 본문이 비어 있어 확인 불가 | 시도한 URL과 결과를 적음 |
| `[미확인]` | 어떤 방법으로도 확인하지 못함 | 확인에 필요한 조건을 적음 |

**Pleos 문서 페이지의 현재 상태** `[실측]`
```
agent-browser open https://document.pleos.ai/en/docs/.../tire/get-low-tire-pressure
agent-browser eval "document.body.innerText"
→ 사이드바 메뉴만 출력됨. 본문 0줄.
```
따라서 페이지 본문을 직접 인용할 수 없다. 문서 근거는 **검색 엔진이 보관한 스니펫**만 쓸 수 있고, 그 경우 `[문서-스니펫]` 으로 표시한다.

### 0-2. 판정 규칙

1. 기대값은 `uiautomator` XML의 `text` 값과 **문자 단위로 비교**한다. 눈으로 읽지 않는다.
2. 기대값이 둘 이상이면 **모두 일치**해야 통과다. 하나라도 다르면 실패다.
3. 이 문서에 없는 항목은 채점하지 않는다.
4. `[미확인]` 등급이 붙은 값은 채점에 쓰지 않고 `해당없음`으로 적는다.

### 3-3. `getLowTirePressure` — 문서 스니펫 원문

```
Gets the critically low tire pressure threshold in kilopascals (kPa).
Permission: PleosPermission.CAR_SAFETY (protection level: normal).
```
출처: https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle/ai.pleos.playground.vehicle.api/tire/get-low-tire-pressure (검색 스니펫, 2026-11-11) `[문서-스니펫]`

**판정에 미치는 영향**: 이 API는 "이 바퀴가 저압인가"를 알려 주지 않는다. **임계값** 하나를 알려 준다. 저압 판정은 `getTirePressure`(실제 압력)와 이 임계값을 비교해 앱이 해야 한다.

현재 앱은 `value > 0f` 를 저압으로 센다 `[실측]` (`PleosVehicleSource.kt:173`). 이는 임계값을 플래그로 오해한 것이므로 **기준 위반**이다.

### 3-6. 에뮬레이터 예외 `[실측]`

에뮬레이터에서 `PRIVATE_CAR_SAFETY` 는 `protectionLevel=normal` 로 선언돼 있어 일반 앱이 받는다.
```
adb shell dumpsys package ai.pleos.playground.service.vehicle | grep PRIVATE_CAR_SAFETY
→ prot=normal
```
**실차에서는 signature|privileged 이므로 일반 앱이 받지 못한다.** 에뮬레이터 동작을 실차 근거로 쓰지 않는다.

## 4. 데모 D3 기준값

사전조건: 설정에서 데모 모드 ON, 시나리오 `D3`.

입력: 엔진오일 `NORMAL`, 브레이크액 `NORMAL`, 저압 바퀴 1개, SOC 62, 경고등 `ABS=RED`+`TPMS=YELLOW`, 관리 53.

| 값 | 기대 | 계산 |
|---|---|---|
| 동력 | `100` | 100 − 0 |
| 제동·조향 | `50` | 100 − 50 (ABS RED) |
| 타이어 | `75` | 100 − 25 (TPMS YELLOW −25가 저압 −20보다 큼. 같은 원인 묶음이므로 큰 값 하나만) |
| 전기 | `100` | 100 − 0 |
| 안전 | `100` | 100 − 0 |
| 건강 | `85` | (100+50+75+100+100)/5 |
| 관리 | `53` | 데모 기록 7회 규칙 계산 (`Demo.CARE_TODAY`) |
| 종합 내부 | 75.4 | 85×0.7 + 53×0.3 |
| 종합 화면 | `75` | 75.4 내림 |
| 등급 | `B` | 75.4 |
| 다음 등급까지 | `5` | 80 − 75.4 = 4.6 올림 |
| 주의 개수 | `2` | 경고등 ON 2개 |
