# MOCA 평가기준

- 작성 2026-11-11 · 대상 `ai.moca.app` (Pleos Connect, Vehicle SDK 2.3.2)
- 목적: 판정자가 재량을 넣을 칸을 만들지 않는다. 결과는 `통과` / `실패` / `해당없음` 셋뿐이다.
- 기대값은 **화면에 실제로 나오는 문자열 또는 숫자**다. 판정자는 `uiautomator` XML의 `text` 값과 문자 단위로 비교한다.

## 0. 판정 규칙

1. 기대값이 둘 이상이면 **모두 일치**해야 통과다.
2. 화면 문자열은 **부분 일치가 아니라 완전 일치**를 본다. 단 §6 표의 `포함` 표기가 있으면 포함 여부만 본다.
3. 이 문서에 없는 항목은 채점하지 않는다.
4. `[미확인]` 값은 채점에 쓰지 않고 `해당없음`으로 적는다.
5. 판정자는 스크린샷을 눈으로 읽지 않는다. `uiautomator dump`의 `text` 를 쓴다.

### 3-2. `getLowTirePressure` 문서 원문

```
Gets the critically low tire pressure threshold in kilopascals (kPa).
Permission: PleosPermission.CAR_SAFETY (protection level: normal).
```
출처: `https://document.pleos.ai/en/docs/pleos-only/connect-sdk-pleos/Vehicle/vehicle/ai.pleos.playground.vehicle.api/tire/get-low-tire-pressure` (검색 스니펫, 2026-11-11) `[문서-스니펫]`

### 4-2. 계산

```
카테고리 = max(0, 100 − Σ(묶음별 최대 감점))
건강     = 측정된 카테고리 평균
종합     = 건강×0.7 + 관리×0.3
등급     = S+ ≥95 · S ≥90 · A ≥80 · B ≥70 · C ≥60 · D <60
RED 있으면 등급 최대 B
건강 문턱: S는 건강 ≥90, S+는 ≥95일 때만 (아니면 A 상한)
측정 카테고리 3개 미만이면 등급 없음(null)
표시: 종합 내림, 남은 점수 올림
```

### 4-3. 데모 D3 절대값

입력: 오일 `NORMAL`, 브레이크액 `NORMAL`, 저압 1개, SOC 62, ABS=`RED`, TPMS=`YELLOW`, 관리 53

| 값 | 기대 | 계산 |
|---|---|---|
| 동력 | `100` | 100 − 0 |
| 제동·조향 | `50` | 100 − 50 (ABS RED) |
| 타이어 | `75` | 100 − 25 (TPMS YELLOW −25 > 저압 −20, 같은 묶음이므로 큰 값만) |
| 전기 | `100` | 100 − 0 |
| 안전 | `100` | 100 − 0 |
| 건강 | `85` | (100+50+75+100+100)/5 |
| 관리 | `53` | `Demo.CARE_TODAY` |
| 종합 내부 | 75.4 | 85×0.7 + 53×0.3 |
| 종합 화면 | `75` | 내림 |
| 등급 | `B` | 75.4 |
| 다음 등급까지 | `5` | 80 − 75.4 = 4.6 올림 |
| 주의 개수 | `2` | 경고등 ON 2개 |
