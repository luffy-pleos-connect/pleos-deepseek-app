# MOCA 평가기준

- 작성 2026-11-11. 대상 패키지 `ai.moca.app`.
- 판정자가 고를 수 있는 결과는 `통과`, `실패`, `해당없음` 뿐이다.
- 채점 행의 기대값은 문자열, 정수, 또는 `enabled` 값이다. 비교는 `완전일치` 또는 `포함` 이다.
- 화면 항목 ID 는 6장 표의 `H-` `I-` `S-` `V-` `B-` `C-` `N-` `R-` 이다. 개수는 58 이다.

## 0. 판정 규칙

1. 한 행의 기대값이 둘 이상이면 모두 맞아야 `통과` 다.
2. `완전일치`: 지목한 노드의 `text` (또는 `enabled`) 가 기대값과 문자 단위로 같다.
3. `포함`: 그 화면에서 모은 `text` 안에 기대값 문자열이 있다.
4. 기대값과 비교가 맞으면 그 행은 `통과` 다. 다르면 `실패` 다.
5. 사전조건을 만들 수 없으면 `해당없음` 이다. 기대값을 다른 문자로 바꾸지 않는다.
6. 7장에 있는 항목은 채점하지 않는다. 기대값을 만들지 않는다.
7. 화면 글자는 `uiautomator dump` 의 `text` 와 `enabled` 만 본다.

수집:

```bash
ADB="$HOME/Library/Android/sdk/platform-tools/adb"
"$ADB" shell uiautomator dump /sdcard/u.xml
"$ADB" shell cat /sdcard/u.xml
```

`Model.kt:50` `active` 는 color 가 `RED` 또는 `YELLOW` 일 때다. `blinking` 필드는 `Rules.deductions` 에 없다.

카테고리 점수는 `max(0, 100 - 그 카테고리 감점 합)` 이다 (`Scoring.kt:19-20`). 측정되지 않으면 null 이다.

`Scoring.kt:9` `MIN_MEASURED_CATEGORIES = 3`. 측정 개수가 3 미만이거나 관리가 null 이면 등급은 null 이다 (`Scoring.kt:77-91`).

`Scoring.kt:94-96` `denominator = 10 * count`, `numerator = sum * 7 + care * 3 * count`. 종합 = `numerator / denominator` (실수).

`Scoring.kt:126` 화면 종합 `displayedOverall = numerator / denominator` (정수 나눗셈).

`Scoring.kt:143-150` 문턱: `S+` 는 95, `S` 는 90, `A` 는 80, `B` 는 70, `C` 는 60, 그 아래는 `D`.

`Scoring.kt:152-155` 건강 합이 `95 * 개수` 이상이면 상한은 `S+` 다. `90 * 개수` 이상이고 `95 * 개수` 미만이면 상한은 `S` 다. 그 밖에는 상한은 `A` 다. `redCap` 이고 등급 ordinal 이 `B` 보다 크면 등급은 `B` 다 (`Scoring.kt:163-166`).

`Scoring.kt:171-172` 다음 등급까지 남은 값은 `ceilDiv`.

`Care.kt:8-15` 관리 시작 `50`, 점검 `+2`, 7일 연속 `+5`, 해소 1건 `+5`, 하루 해소 상한 `10`, 14일 지나면 `-1`.

## 7. 판정불가

아래는 채점하지 않는다. 기대값을 적지 않는다. 결과는 적는다면 `해당없음` 만 허용한다.

| 항목 | 연 근거 | 판정 |
|---|---|---|
| 경고등 color 정수와 RED/YELLOW 의 대응 | `docs/evidence/G0/report.md:78-79` `bridge_ready=false`. 색 정수는 확정하지 못함 | 해당없음 |
| `getLowTirePressure` 반환 Float 의 단위 | 이 세션에서 연 문서 URL 본문에 `kilopascals` 문장이 없었다. 시그니처만 `G0/report.md:95` 에 있다 | 해당없음 |
| `getTirePressure` 의 단위 | `VehicleSDK_실측.md:77` 은 함수가 있다고만 적는다 | 해당없음 |
| 실차에서 `PRIVATE_CAR_SAFETY` 가 거부되는지 | `G0/report.md:52-53` 은 에뮬레이터는 `normal` 이고 실차 재확인이 필요하다고 적는다 | 해당없음 |
| 세로 창에서 앱 노드가 있는지 | `docs/진행일지.md:78` 은 `wm size` 이후 창 서비스가 멈췄다고 적는다. 이 세션에서 다시 재지 않았다 | 해당없음 |
| 마이크 하드웨어가 음성을 받는지 | `VoiceFragment.kt:33-34` 는 에뮬레이터에 마이크가 없으면 인식이 되지 않는다고 적는다. 이 세션에서 기기를 열지 않았다 | 해당없음 |
| 점검 뒤 `lastInspection` 의 날짜 | 기록이 있으면 `InspectionHistory.label` (`M월 d일`). 없으면 `아직 점검한 적이 없어요`. 날짜는 점검일에 따라 달라 고정 기대값을 두지 않는다 | 해당없음 |
| 상태관리 추이의 시각 라벨 | 기록이 2줄 이상이면 `M월 d일` 과 그날 화면 종합. 1줄 이하면 현재 카테고리 막대. 날짜가 고정이 아니라 기대값을 두지 않는다 | 해당없음 |
| 서버가 답을 돌려준 뒤의 보이스 문장 | `VoiceAgent.kt:77-80` 은 모델 `content` 를 그대로 쓴다. 고정 문장이 아니다 | 해당없음 |
| 응답까지 걸린 시간의 상한 | 코드에서 연 구간에 초 단위 합격 상한 상수가 없다 | 해당없음 |
