# MOCA 평가기준 (판정 가능 기준)

- 작성: 2026-11-11
- 이 문서는 **판정자가 재량을 넣을 칸을 만들지 않는 것**을 목적으로 한다.
- 판정 값은 `통과` / `실패` / `해당없음` 셋뿐이다.
- 모든 기대값은 **화면에 표시되는 문자열 또는 숫자**로 적는다.

## 0. 이 문서의 규칙

1. 각 항목은 `사전조건 → 조작 → 관찰 지점 → 기대값` 순서로만 적는다.
2. 기대값은 **인용 부호 안의 문자열** 또는 **숫자**로 적는다. 둘 다 아니면 그 항목은 이 문서에 넣지 않는다.
3. 판정자가 기대값과 화면 값을 **문자 단위로 비교**한다. 다르면 실패다.
4. 이 문서에 적힌 금지어가 0건일 때만 이 문서를 기준으로 쓴다. 검사 명령은 §8에 있다.

## 3. 데모 D3 기준값 (판정 기준표)

사전조건: 설정에서 데모 모드 ON, 시나리오 `D3`.

입력: 엔진오일 `NORMAL`, 브레이크액 `NORMAL`, 저압 바퀴 1개(FL), SOC 62, 경고등 `ABS=RED` + `TPMS=YELLOW`, 관리 53.

| 값 | 기대 | 계산 |
|---|---|---|
| 동력 | `100` | 100 − 0 |
| 제동·조향 | `50` | 100 − 50 (ABS RED) |
| 타이어 | `75` | 100 − 25 (TPMS YELLOW −25가 저압 −20보다 큼. 같은 원인 묶음이므로 큰 값 하나만) |
| 전기 | `100` | 100 − 0 |
| 안전 | `100` | 100 − 0 |
| 건강 | `85` | (100+50+75+100+100)/5 = 85.0 |
| 관리 | `53` | 데모 기록 7회 규칙 계산 |
| 종합(내부) | 75.4 | 85×0.7 + 53×0.3 |
| 종합(화면) | `75` | 75.4 내림 |
| 등급 | `B` | 75.4 |
| 다음 등급까지 | `5` | 80 − 75.4 = 4.6 올림 |

### 5-7-1. `getLowTirePressure` 구현 규칙 (고정)

문서상 반환값은 **kPa 단위 임계값**이다. **"저압이면 1.0" 플래그가 아니다.**

앱은 다음을 만족해야 통과한다.
1. 앱이 `getLowTirePressure` 반환값을 **저압 개수로 세지 않는다**.
2. 저압 판정은 `getTirePressure`(실제 압력)와 임계값을 비교해 앱이 한다.
3. `getTirePressure`를 쓸 수 없으면(아래 5-7-2) 타이어 압력 항목을 **측정 불가**로 표시한다.

**현재 구현 판정: 실패.**
- `PleosVehicleSource.kt:173` 이 `value > 0f` 를 저압으로 센다. 임계값을 저압 플래그로 오해한 구현이다.
- 그러면 저압이 **아닌** 바퀴도 임계값이 0보다 크면 저압으로 세어진다.

### 5-7-2. `getTirePressure` 사용 불가

문서상 필요 권한은 `PRIVATE_CAR_SAFETY`, protection level **Signature|Privileged** 다.
일반 앱은 이 권한을 받을 수 없다.

**따라서 기준표는 다음으로 고정한다.**
- `getTirePressure`와 `getTelltalesInfo`/`registerTelltales`/`checkTelltalesCapabilities` 는 **일반 앱 사용 불가 API**로 분류한다.
- 이 API에 의존하는 화면 기능(경고등 배지, 타이어 실제 압력 표시)은 **"실차 미확인"으로 표시**하고, 판정에서 `해당없음` 으로 적는다.
- 에뮬레이터에서 `protectionLevel=normal` 로 동작하는 것은 **에뮬레이터 예외**이며 실차 근거가 아니다.

### 5-7-3. 문서에서 확인한 오타 (구현 시 주의)

`Safety.registerLowWasherFluidWaringState` — **"Waring"** 오타가 API 이름과 문서 URL에 그대로 있다. `Warning`으로 고쳐 쓰면 컴파일이 안 된다.
