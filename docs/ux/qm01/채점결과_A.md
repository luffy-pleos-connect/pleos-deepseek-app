# 채점결과 A — 홈 화면 와이어프레임 (등급 카드 좌측 + 기능 타일 2×2)

평가자: 독립 평가자 / 평가일: 2026-11-10
대상: `wireframe_A.png` (좌측 대형 등급 카드, 우측 기능 타일 2×2)

## 2초 테스트

> **한 문장**: "등급은 B이고, 점검·상태관리 등 기능 4개를 고를 수 있는 화면이다."

- 좌측 상단의 대형 "B" 등급 카드가 시선을 먼저 뺏는다. 등급 + "A까지 7점"은 즉시 인식된다.
- 다만 2초 안에 "주의가 있나(주의 개수)"는 잡히지 않는다 — "주의 없음"이 카드 하단 3번째 줄에 일반 텍스트로 섞여 있다.
- 기능 타일(점검하기 등)은 우측에 있어 2초 내 "다음 행동"으로는 약간 늦게 잡힌다.

## 판단

### 운전자가 2초에 이해할 수 있는가?
**부분적으로 가능.** 등급(B)과 잔여 점수는 즉시 이해된다. 그러나 P1의 나머지 절반인 "주의 개수"는 카드 내 하단 나열에서 눈에 덜 띄어, "지금 뭔가 손봐야 하나?"라는 질문에는 2초 안에 답하지 못할 수 있다.

### 좁은 창(628×855dp)에서 P1과 주 동작이 남을 것 같은가?
**P1은 남음, 주 동작은 위험.** 세로 855dp에서 등급 카드(원본 비율로 약 60% 높이)가 유지되면 타일 2×2가 첫 화면에서 잘리거나 스크롤을 요구할 수 있다. 카드 높이가 정보량 대비 과도하게 커서 좁은 창에서 공간 낭비가 커진다.
