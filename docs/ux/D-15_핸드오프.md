# D-15 배치·흐름 핸드오프 (정태양 님께 전달용)

작성일: 2026-11-10
대상: Pleos Connect Design System 담당
목적: MOCA 앱의 **정보 구조·배치·흐름·상태·문구**를 넘기고, DS에 없는 **조합 컴포넌트**의 조합 방식 검토를 요청한다.
시각 결정(색·글꼴·아이콘·모션 모양)은 이 문서에서 정하지 않는다. 전부 DS 토큰을 쓴다.

---

## 1. 앱 개요

- Pleos Connect 차량 앱. FragmentActivity 1개 + Fragment 7개.
- 레이아웃: `layout/`(가로, 2열) + `layout-port/`(세로, 1열)
- 테마: `Theme.PleosConnect`. `values-night` 자동 전환. 코드에서 강제하지 않는다.
- 여백: 가장자리 48dp, 컴포넌트 간격 24dp

## 2. 정보 구조

```
홈 (P1: 내 등급 + 주의 개수)
├─ 점검하기 → 점검 결과 → 상태관리
├─ 상태관리 (카테고리 5 + 할 일 + 추이)
├─ AI 보이스 (마이크 + 추천 질문 + 도구 칩)
├─ 대전하기 (로비 → 5라운드 → 결과)
└─ 설정 (닉네임·데모 모드·동의·데이터 삭제·면책)
첫 실행 (동의 3 + 닉네임) — 홈 앞에 1회
주행 중 팝업 (제한 안내 + 음성으로 물어보기)
```

## 3. 화면별 P1/P2/P3와 배치

| 화면 | P1 | P2 | P3 | 주 동작 |
|---|---|---|---|---|
| 홈 | 내 등급 + 주의 n | 종합·건강·관리, 다음 등급까지 | 마지막 점검 경과일 | 각 타일 진입 |
| 점검 결과 | 등급(변화 포함) | 지난번 대비, 관리 변화 이유, 카테고리 5 | 감점 상위 3 | 상태관리로 |
| 상태관리 | 가장 나쁜 카테고리 | 카테고리 5 점수·상태, 할 일 | 추이 | 카드 상세 |
| 상세 | 문제 항목과 조치 | 원본값·감점·이유 | 지원 여부 | 닫기 |
| 보이스 | 지금 상태 + 최근 답 | 도구 칩 | 대화 이력, 추천 칩 | 마이크 |
| 대전 | 결과 | 라운드 5 | 전적 | 다시 / 홈 |
| 주행 중 | 제한 안내 1줄 | – | – | 음성으로 묻기 |

## 4. DS에 없어 조합한 컴포넌트 (검토 요청)

| 컴포넌트 | 쓰는 곳 | 구현 | 상태 |
|---|---|---|---|
| 등급 카드 | 홈·결과·대전 | `Widget.Pleos.Card`(style) + `Pleos.Text.Headline.L`(등급) + `Pleos.Text.Title.M`(종합·건강·관리) + `Pleos.Text.Label.M`(라벨) | 기록 없음 / 정상 / RED 상한 / 데모 |
| 카테고리 카드 | 결과·상태관리 | `Widget.Pleos.Card`(style) + `Pleos.Text.Title.S`(이름) + `Pleos.Text.Body.M`(점수·상태) + 시맨틱 색 | 정상/주의/위험/측정 불가 |
| 기능 타일 | 홈 | `Widget.Pleos.Card`(style) + `Pleos.Text.Title.S` + `Pleos.Text.Label.S` | 기본/눌림/주행 중 비활성/알림 점 |
| 도구 칩 | 보이스 | `Pleos.Text.Label.M` + `Widget.Pleos.Card` 축소 | 실행 중/완료/실패 |
| 라운드 행 | 대전 | `Pleos.Text.Body.M` + 시맨틱 색 | 대기/공개/승/패/무 |
| 상태 배지 | 전체 | `Pleos.Text.Label.M` + `pleos_text_dark_secondary` | 데모/오프라인/주의 n |

| 주의 | `@color/pleos_regulation_yellow` | |

## 5. 버튼 위계

- 화면당 Filled(`Widget.Pleos.Button.Secondary.*`) **1개** = 주 행동
- 나머지 Basic(`Widget.Pleos.Button.Primary.*`)
- 크기 L 100 / M 80 / S 64dp. 터치 최소 64dp
- 예: 점검 결과 → [상태관리에서 보기](Secondary.M) + [다시 점검](Primary.M)

## 6. 주행 중 규칙 (우리 몫)

| 화면 | 주행 중 |
|---|---|
| 홈 | 등급·경고 배지 표시. 타일 탭 → 제한 팝업 |
| 점검·상태관리·대전 | "주행 중에는 화면 조작이 제한돼요" + [음성으로 물어보기] |
| 보이스 | 동작. 답 2문장 이내, 화면 2줄 이내 |
| 설정 | 진입 제한 |

- 구현: `PleosUxRestrictions` 로 `distractionOptimized` 상태를 받아 상태관리·대전 탭을 비활성화한다.
- 모션 0. 반복 애니메이션 0.
